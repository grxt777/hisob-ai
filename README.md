# Hisob AI

AI-команда для бухгалтерии малого бизнеса в Узбекистане: менеджер, бухгалтер, юрист и аналитик работают в одном пространстве. Агенты заполняют документы прямо на холсте, курсорами, у пользователя на глазах.

Прототип для National AI Hackathon 2026, трек «Голосовой AI-бухгалтер» (микро- и малый бизнес).

## Что умеет

- **Связи Soliq / 1С / Didox:** вкладка «Связи» — песочница или боевой API (token/логин). Синхронизация ЭСФ пишет в `data/live-esf.json` и подменяет реестры в расчёте. Также можно загрузить выгрузку Excel/CSV/JSON. Секреты только локально в `data/` (в git не попадает).
- **Пульс денег:** банк + касса (приход/расход/остаток), дебиторка и кредиторка, график аренды и кредита.
- **Возможности:** НДС 6%, взыскание дебиторки, кассовый разрыв, план «сегодня · 3 действия».
- **Расчёт НДС из ЭСФ:** бухгалтер сводит реестры продаж и покупок, юрист проверяет, что идёт в зачёт, аналитик сравнивает режимы (общий, упрощённый НДС 6% по УП-100, налог с оборота) и показывает экономию и риски.
- **Действия только с разрешения:** Excel, заявление, напоминание, пульс денег. Пакет к ЭЦП с чеклистом — отправка останавливается до подписи руководителя.
- **Чат с менеджером (текст и голос UZ/RU):** менеджер управляет экраном через инструменты:
  - открывает документы и блоки отчёта;
  - создаёт любые документы (приказ, заявление, письмо в налоговую и т. д.);
  - выгружает их в PDF, Word или Excel;
  - отвечает на вопросы по ЭСФ («кто крупнейший покупатель?»);
  - считает через калькулятор;
  - ставит напоминания.
- **ИИ-курсор:** отмечаете любое место в документе и спрашиваете о нём.
- **Геомодель:** карта предприятия в 2D или 3D (MapLibre и OpenFreeMap). Точку можно найти по адресу или отметить кликом. Для бизнеса, которому важны прохожие (пекарня, магазин, кафе, салон, аптека, учебный центр), считается индекс проходимости 0–100. Индекс строится по точкам притяжения OpenStreetMap в радиусе 300 м (остановки, рынки, школы, кафе…) и показывается как оценка, а не как число людей. Для офиса, склада и онлайн-бизнеса трафик не считается.
- **Здание → этаж → помещение:** клик по дому выделяет его и разрезает на этажи. Этажность берётся из OSM и сверяется с высотой дома: если данные противоречат друг другу, это показывается прямо в интерфейсе. Этаж выбирается кликом по 3D-модели или кнопками-«лифтом». На плане этажа (контур дома из OSM) можно загрузить картинку планировки и обвести своё помещение: площадь считается по контуру, а само помещение появляется розовым на 3D-модели. Квартиры и комнаты не выдумываются: их задаёт пользователь своим планом.
- **Маркетолог: аналитика каждого поста.**
  - **Telegram** — публичная лента канала, до 60 постов с подгрузкой старых. По каждому посту: просмотры, реакции с разбивкой по эмодзи, формат, время. Статистика: формат, день, час (по Ташкенту), длина текста, хэштеги, вовлечённость, частота. Рекомендации, что и когда публиковать, и идеи следующих постов; цифры в них проходят ту же проверку на выдумку.
  - **Instagram** — аналитика по постам и охват только через официальный Instagram API владельца (`INSTAGRAM_ACCESS_TOKEN` в `.env`). Без токена доступны только публичные счётчики профиля.
  - **«Наши» аккаунты** запоминаются (`data/social.json`, в репозиторий не попадает) и перечитываются каждые 6 часов. У каждого поста копится история: прирост просмотров между проверками.
- **MCP, инструменты без ограничений:** каждый сервер из `mcp.json` подключается при старте, и его инструменты становятся доступны модели. Сейчас подключён Playwright MCP (браузер). Чтобы добавить новый инструмент, достаточно дописать сервер в `mcp.json`, код менять не нужно.
- **Hisob как MCP-сервер:** `mcp-server.js` отдаёт наши инструменты (`vat_summary`, `query_invoices`, `calculate`, `social_monitor`, `geocode`) в Claude Desktop, Cursor или любой другой MCP-клиент.
- **Запрет на выдумывание данных:** любая цифра в ответе или документе сверяется с данными, словами пользователя и результатами инструментов. Если цифры там нет, модель переписывает ответ, а если и это не помогло, ответ блокируется.

## Запуск

Нужен Node 18+.

```bash
npm install
npx playwright install chromium   # браузер для соцсетей и MCP
cp .env.example .env              # впишите OPENROUTER_API_KEY
node server.js                    # http://localhost:5180
```

Подключить Hisob к Claude Desktop или Cursor как MCP-сервер:

```json
{ "mcpServers": { "hisob": { "command": "node", "args": ["/путь/к/hisob/mcp-server.js"] } } }
```

Проверка MCP-сервера: `node test/mcp-server.test.mjs`.

Без ключа работает главный сценарий (расчёт НДС), а чат отвечает по ключевым словам.

## Устройство

| Файл | Что внутри |
|---|---|
| `server.js` | Статика и `/api/chat`: OpenRouter (`z-ai/glm-5.3-flash`), цикл инструментов, проверка цифр |
| `public/assets/hisob.js` | Интерфейс, сценарий агентов, действия на экране, экспорт PDF/DOCX/XLSX |
| `public/assets/data.js` | Реестры ЭСФ за октябрь 2026: названия и ИНН вымышленные, суммы из реального шаблона |
| `public/assets/styles.css`, `cowork.css`, `app.js`, `icons.js` | Дизайн-система dominify.designs |
