# Hisob AI

AI-команда для бухгалтерии малого бизнеса в Узбекистане: менеджер, бухгалтер, юрист и аналитик работают в одном пространстве. Агенты заполняют документы прямо на холсте, курсорами, у пользователя на глазах.

Прототип для National AI Hackathon 2026, трек «Голосовой AI-бухгалтер» (микро- и малый бизнес).

## Что умеет

- **Расчёт НДС из ЭСФ:** бухгалтер сводит реестры продаж и покупок, юрист проверяет, что идёт в зачёт, аналитик сравнивает режимы (общий, упрощённый НДС 6% по УП-100, налог с оборота) и показывает экономию и риски.
- **Действия только с разрешения:** Excel, заявление, напоминание. Отправка в налоговую останавливается перед подписью ЭЦП.
- **Чат с менеджером (текст и голос UZ/RU):** менеджер управляет экраном через инструменты:
  - открывает документы и блоки отчёта;
  - создаёт любые документы (приказ, заявление, письмо в налоговую и т. д.);
  - выгружает их в PDF, Word или Excel;
  - отвечает на вопросы по ЭСФ («кто крупнейший покупатель?»);
  - считает через калькулятор;
  - ставит напоминания.
- **ИИ-курсор:** отмечаете любое место в документе и спрашиваете о нём.
- **Запрет на выдумывание данных:** любая цифра в ответе или документе сверяется с данными, словами пользователя и результатами инструментов. Если цифры там нет, модель переписывает ответ, а если и это не помогло, ответ блокируется.

## Запуск

Нужен Node 18+, зависимостей нет.

```bash
cp .env.example .env   # впишите OPENROUTER_API_KEY
node server.js         # http://localhost:5180
```

Без ключа работает главный сценарий (расчёт НДС), а чат отвечает по ключевым словам.

## Устройство

| Файл | Что внутри |
|---|---|
| `server.js` | Статика и `/api/chat`: OpenRouter (`z-ai/glm-5.3-flash`), цикл инструментов, проверка цифр |
| `public/assets/hisob.js` | Интерфейс, сценарий агентов, действия на экране, экспорт PDF/DOCX/XLSX |
| `public/assets/data.js` | Реестры ЭСФ за октябрь 2026: названия и ИНН вымышленные, суммы из реального шаблона |
| `public/assets/styles.css`, `cowork.css`, `app.js`, `icons.js` | Дизайн-система dominify.designs |
